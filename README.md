# Machine Learning

A collection of **machine learning notebooks** covering fundamental supervised and unsupervised learning techniques, with practical examples and visualizations.

## Project Structure

```text

│   ├── 1_Regression/
│   ├── 2_Logistic_Regression/
```

## Topics

### Supervised Learning

* Linear and polynomial regression
* Gradient descent
* Logistic regression
* Regularization
* Neural networks
* Multiclass classification
* Model evaluation and selection
* Bias and variance
* Decision trees
* Ensemble methods

The notebooks also include practical examples such as house-price prediction, handwritten digit classification, and heart-disease prediction.

### Unsupervised Learning

* K-Means clustering
* Image compression
* Anomaly detection
* Collaborative filtering
* Content-based recommendation
* Principal Component Analysis (PCA)

These examples demonstrate how unsupervised methods can be used for clustering, dimensionality reduction, recommendation systems, and detecting unusual data points.

## Usage

Clone the repository:

```bash
git clone https://github.com/SadeghMahmoudAbadi/Machine-Learning.git
cd Machine-Learning
```

Install the main dependencies:

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow jupyter
```

Then open any notebook:

```bash
jupyter notebook
```

## Purpose

This repository is mainly for **learning and practicing machine learning concepts** through hands-on implementations and examples.
